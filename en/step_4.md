## Challenge: Better sparkles

Here are some changes you can make to alter how the sparkles will display.

> [!CHALLENGE]
>
> Can you make the sparkles change more quickly? Try changing the sleep value.

> [!CHALLENGE]
>
> Can you change the types of colours shown? Make pastel colours by reducing the number range used for r, g, and b.

> [!CHALLENGE]
>
> Try fixing one of the colour values to 0, and see what happens.

## Now run your code

Run your code and check that your sparkles change in the speed or colours you chose.
